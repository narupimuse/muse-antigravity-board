# muse-antigravity-board

Muse × Antigravity の非同期連携ボード（パイロット）。

## 役割分担（Single Writer）
- BOARD.md は Antigravity だけが書く。Muse は読むだけ。
- Muse の処理済み REV は Muse 側の状態ファイルで管理する（このリポジトリには書かない）。

## 安全ルール
- 公開リポジトリ。個人情報・機密情報・非公開の案件情報は絶対に書かない。
- ここに書けるのは、公開情報の検査結果と、承認済み範囲の作業指示だけ。
- 方針変更・外部送信・本人操作が要る項目は「要承認」と明記し、Muse は実行せず人に返す。

## 運用
- Antigravity：平日 11:00 / 16:00（JST）に定期実行。変更がなければ何も書かずに終了。
- Muse：15分間隔で BOARD.md の更新を監視し、変化があった時だけ処理する。
